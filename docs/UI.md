# User Interface (UI) Specifications - sAI

This document details the visual layouts and structures of the user interfaces for sAI.

## REPL (primary) -- `sai`
`app/repl.py`, built on Rich and prompt_toolkit, modeled on Claude Code:
* A transient spinner names who is working (`✻ Coder thinking… (8s · ↑ 7.5k tokens)`)
  and shows the reply streaming in.
* Agent messages render as Markdown under `⏺ AgentName`; tool calls as
  `⏺ Write(path)` with a `⎿` result line; edits show a colored diff and `Allow? [y/N/a]`.
* Input: history, multi-line (`\` or Option+Enter), Tab completion for `/commands` and
  `@files`, Esc/Ctrl+C to stop a turn.
* A footer per turn shows the route Jev chose and the tokens used.
See the README for commands and settings; `ui/activity.py`, `ui/input.py` and
`ui/esc_watcher.py` hold the rendering and input code.

## Terminal UI (TUI) -- `sai tui`
An older Textual interface (`ui/terminal.py`); it shares the agents and tool-use loop but
not the REPL's newer display and input features. Built using the `Textual` and `Rich` frameworks.

### WhatsApp-like Thread Concept
Unlike standard single-scroll terminals, sAI formats conversations as distinct, clean communication streams. The user sees:
* Main thread showing structured prompts and key agent reports.
* Side-by-side or collapsible visual details for every execution step.

### Step-by-Step Expansion
Every message card generated by an agent can be toggled/expanded to review:
1. **Thinking**: The internal chain-of-thought (CoT) of the agent.
2. **Tool Calls**: The tools invoked, their input arguments, and verification status.
3. **Agent Collaboration**: Which sub-agents were triggered and their responses.
4. **Diffs**: A color-coded code comparison block showing proposed changes.
5. **Memory Updates**: Entities added/deleted from Graphiti or short-term memory changes.
6. **Files**: Links to local files read or modified during the turn.
7. **Logs**: Verbose subprocess, API headers, token counts, and terminal stdout logs.

## Desktop UI (Future)
* **Framework**: Electron / Tauri.
* **Goal**: Provide a clean graphical wrapper running locally on Mac, Linux, or Windows.
* **Features**:
  * Side-by-side terminal, folder tree view, and live knowledge graph canvas.
  * Easy visual toggle of agent permissions.

---

## Web UI (Future)
* **Framework**: React / Tailwind CSS with FastAPI backend.
* **Goal**: Remote workspace accessibility and server deployment interfaces.
* **Features**:
  * Multi-user real-time workspace collaboration.
  * Shared model costing dashboard.
