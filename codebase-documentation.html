sAI Project Overview

sAI is an asynchronous, event-driven multi-agent AI operating system. The system coordinates specialized agent roles—Planner, Architect, Coder, and Reviewer—collaborating over a centralized event bus to analyze, modify, and verify your codebase safety sandboxes.

💡 Core Architecture Principles

The design prioritizes host isolation (Docker subprocess sandboxing), deterministic rollbacks (SQLite-backed transaction snapshots), JIT search indexing, and a thread-safe unified CLI gateway.

while current_agent_name and turns < max_turns:
    turns += 1

Deep-Dive: Security & Rollbacks

The core/security.py module manages file state logs, single-use execution whitelists, and time-travel rollback sliders inside transactions.db.

API Signature Walkthrough

Method Parameters Return Type Description
save_transaction_snapshot(session_id, path_str) session_id: str, path_str: str None Logs a file's state (before edit) to the transactions database.
revert_transaction(transaction_id) transaction_id: int tuple (bool, str) Restores a single file back to its pre-patch state.
revert_to_transaction_snapshot(session_id, target_tx_id) session_id: str, target_tx_id: int tuple (bool, str) Performs batch rollback of all edits chronologically back to a specific moment.

Code Highlight: Time-Travel Rollback Algorithm

core/security.py
def revert_to_transaction_snapshot(session_id: str, target_tx_id: int) -> tuple:
    conn = sqlite3.connect(str(TRANSACTIONS_DB))
    cursor = conn.cursor()
    
    # Retrieve all transaction edits from target_tx_id onwards in reverse chronological order
    cursor.execute(
        "SELECT id, path, before_content FROM file_transactions WHERE session_id = ? AND id >= ? ORDER BY id DESC",
        (session_id, target_tx_id)
    )
    rows = cursor.fetchall()
    
    reverted_paths = []
    for tx_id, path_str, before_content in rows:
        target_path = Path(path_str)
        if before_content is None:
            # File was created; clean it up on revert
            if target_path.exists():
                target_path.unlink()
        else:
            # Re-write the pre-patch content snapshot
            target_path.write_text(before_content, encoding="utf-8")
        reverted_paths.append(path_str)
        
    cursor.execute("DELETE FROM file_transactions WHERE session_id = ? AND id >= ?", (session_id, target_tx_id))
    conn.commit()
    conn.close()
    return True, f"Reverted {len(reverted_paths)} edits."

Deep-Dive: LLM Runtime Pipeline

Coordinates API queries, token trackers, model routing configurations, and exponential waits inside llm/runtime.py.

@retry(
    stop=stop_after_attempt(3),
    wait=wait_exponential(multiplier=1, min=2, max=10),
    reraise=True
)
def query(self, prompt: str, task_kind: str, temperature: float = 0.2) -> str:
    # Router picks model based on task type (e.g. Coder -> o1-mini, Reviewer -> gpt-4o)
    provider_name, model_name = ModelRouter.route(task_kind)
    
    event_bus.publish(EventType.LLM_REQUEST, {"model": model_name, "provider": provider_name})
    provider = kernel.get_provider(provider_name)
    
    response_content = provider.complete(messages, model=model_name, temperature=temperature)
    return response_content

Deep-Dive: Filesystem Toolset

The filesystem tools in tools/filesystem.py safeguard the disk, verifying boundaries before mutations and logging transaction snapshots.

Code Highlight: Sandboxed Write Tool

tools/filesystem.py
class WriteFileTool(BaseTool):
    def execute(self, args: Dict[str, Any]) -> str:
        path_str = args.get("path")
        content = args.get("content", "")
        
        target_path = Path(path_str)
        if not target_path.is_absolute():
            target_path = get_current_workspace() / target_path
            
        # Sandbox boundary security check
        if not validate_path(target_path):
            return "Error: Path is outside workspace boundaries."
            
        # Capture rollback snapshot prior to edit
        from core.security import save_transaction_snapshot
        save_transaction_snapshot(CURRENT_SESSION_ID, str(target_path))
        
        target_path.write_text(content, encoding="utf-8")
        return "File written successfully."

Deep-Dive: Terminal Sandbox Tool

Standard shell execution engine inside tools/terminal.py wrapping subprocess operations with ephemeral Docker containers to shield host.

Code Highlight: Docker Isolation Interceptor

tools/terminal.py
class TerminalTool(BaseTool):
    def execute(self, args: Dict[str, Any]) -> str:
        cmd = args.get("command", "")
        settings = load_settings()
        
        # Intercept and wrap command inside Docker Alpine container if sandbox is ON
        if settings.get("docker_sandbox", False):
            cwd = get_current_workspace()
            run_cmd = f'docker run --rm -v "{cwd}":/workspace -w /workspace alpine sh -c {repr(cmd)}'
        else:
            run_cmd = cmd
            
        result = subprocess.run(
            run_cmd,
            shell=True,
            stdout=subprocess.PIPE,
            stderr=subprocess.PIPE,
            text=True,
            timeout=15.0
        )
        return result.stdout if result.returncode == 0 else result.stderr
