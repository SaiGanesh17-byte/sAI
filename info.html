How Revert Transactions Work

Before every tool-initiated file edit, sAI captures the exact state of the target file. If a file is newly created, it records a Null history. These snapshots are written to the database. Clicking Undo retrieves the snapshot and restores the filesystem, deleting the file if it didn't exist before.

Command Execution Security Gates

To prevent security leaks, all commands matching shell-dangerous keywords are held at a gateway thread lock. An event is dispatched to the UI rendering a confirmation dialog. Granting approval releases the gate once, consuming the approved token immediately.

[SYSTEM GATE] Intercepted Shell Command: rm -rf tests/__pycache__
-> Command matches prefix rule: "rm "
-> Thread suspended. Dispatched EventType.SECURITY_AUTH_NEEDED
Waiting for User authorization... [Approve (Single-use) / Reject]
-> User Approved. Added approved command token to set.
[SYSTEM RELEASE] Released lock. Command executed inside sandbox.

Quick Start & Setup

Get sAI up and running locally in under 3 minutes.

1. Clone & Set Environment

Ensure you have python 3.8+ and pip configured. Setup your remote API Keys:

BASH
git clone https://github.com/SaiGanesh17-byte/sAI.git
cd sAI
cp .env.template .env

2. Install Dependencies

Build virtual environment and compile standard requirements:

BASH
python3 -m venv venv
source venv/bin/activate
pip install -r requirements.txt

3. Start the sAI Application

sAI offers three visual interface options to interact with your codebase depending on your workflow:

Option A: Interactive Web Dashboard (Recommended)
Launches the full neumorphic visual dashboard on port 8000 (includes file pinning, CPU profilers, and DAG inspects).
BASH
python3 app/main.py --web
Option B: Interactive Terminal TUI Console
Launches a premium terminal interface with a side-by-side chat history container and inspector.
BASH
python3 ui/terminal.py
Option C: Minimalist CLI prompt
Launches a lightweight conversational interface directly in your shell stream.
BASH
python3 app/main.py --cli
