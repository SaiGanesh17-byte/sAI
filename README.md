# sAI

A modular, event-driven Multi-Agent AI Operating System bringing 'Perplexity Labs + Cursor + Claude Code' capabilities to the terminal and web. Features persistent transaction undo/redo history, Monaco playpad, Spotlight search, sandboxed execution safety gates, and dynamic graph memory indexing.

### Prerequisites
- Maven must be installed and configured properly in your system.
Maven installation instructions: https://maven.apache.org/install.cgi
